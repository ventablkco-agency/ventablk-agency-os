# Repository-native Agent Playbooks

This directory contains the agency-owned workflow and manual fallback checklists for the design/tooling stack documented in AGENT_SKILLS.md.

Before every substantial website task, read ventablk-website-workflow/SKILL.md and apply all five review gates: VoltAgent design reference selection, Taste Skill art direction, Impeccable critique, Vercel guideline review, and Playwright browser QA. Execute the upstream tools when installed/connected; otherwise conduct and report a manual review rather than pretending the tool ran.

Repository documentation does not install external tools into ChatGPT or VS Code. Official sources and installation instructions are documented in AGENT_SKILLS.md.

Do not copy full upstream skill implementations into this public repository without reviewing licenses, provenance and update procedures. Keep client data and generated repository inventories out of public source control.
